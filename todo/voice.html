Voice-clone bake — что делать на M4

Phase A: Chatterbox Multilingual (базлайн) → потом shootout с S1-mini / GPT-SoVITS

Created 24-08-2026 · Dr. Mārcis Gasūns · галочки хранятся в этом браузере (localStorage)

Машинный гейт
  • Всё ниже — только на M4 Mac.
  • Windows-бокс (GTX 1050 4 GB) слаб — там работает только агент (обучение SoVITS), руками ничего не запускать.
  • Клонировать реального человека — только с его письменным разрешением (permission.txt). Свой голос / вымышленный персонаж — свободно.

Шаг 0 — если OpenCode на маке ещё не поднят

Сначала пройди runbook миграции: Todo — Mac migration runbook. Для этого бейка из него обязательны: Homebrew + базовые инструменты, gh auth login, клон Uprava.

Чек-лист бейка

  1. Склонировать приватный Uprava и включить его commit-guard: 
    gh repo clone gasyoun/Uprava ~/Documents/GitHub/Uprava
cd ~/Documents/GitHub/Uprava && git config core.hooksPath .githooks
  2. Приготовить ассеты в ~/voice-bake/:

    ref.wav — 10–60 сек целевого голоса: чистая речь, без музыки/фона/эха, моно, ≥22 кГц, WAV/FLAC · permission.txt — одна строка согласия с именем и датой (если голос чужой) · test_text.txt — 2–3 абзаца настоящего русского текста курса.

  3. Открыть OpenCode в папке репо и вставить стартовую строку: 
    Read docs/VOICE_CLONE_M4_BAKE_BRIEF_24.08.26.md and execute it.

    Агент сам поставит окружение (~5 мин), сам остановится и спросит, если ассетов не хватает. Бриф: docs/VOICE_CLONE_M4_BAKE_BRIEF_24.08.26.md (приватный — откроется под твоим логином).

  4. Прослушать три файла out_*.wav (обычный / экспрессивный / медленный) и заполнить вердикт-таблицу агента по 5 критериям (тимбр, русская фонетика, артефакты, просодия, стабильность).
  5. Вердикт: средний ≥4/5 и нет оценок ниже 3 → Phase A принята; иначе — план Б (GPT-SoVITS, обучение на Windows-боксе у агента). Полная матрица: docs/DECISION_VOICE_CLONE_TOOL_24.08.26.md.

Параллельно на Windows-боксе (агент, не ты)

Phase B уже готовится агентом: C:\Users\user\voice-bake\ — GPT-SoVITS склонирован, ждётся HF-токен (hf_token.env) и твои ассеты. Статус: PHASE_B_STATUS.md.
