Как голосовать.

  1. Откройте лист кнопкой Открыть — он загрузится целиком, интернет дальше не нужен.
  2. Проголосуйте по карточкам (approve / reject / defer).
  3. Внизу листа нажмите экспорт — скачается <имя>.decisions.json.
  4. Отдайте этот файл агенту: /decisions-apply применит решения в нужном репозитории.

Прогресс хранится в браузере (localStorage), но не синхронизируется между устройствами — голосуйте один лист на одном устройстве и экспортируйте до закрытия вкладки.
