Причина
Approve = «Значение выбрано»: одно из значений PWG подходит, его номер вписан в поле записи — строка попадает в gold с этой меткой и в знаменатель P@1. Reject = «Не подходит / непригодно» с причиной: none — ни одно значение не подходит (это РЕЗУЛЬТАТ, доля NONE измеряет покрытие нумерованных значений PWG, строка остаётся в знаменателе); proper_name / corrupt / wrong_lemma — строка выбывает из знаменателя. Defer = отложить. Пилот решает, стоит ли размечать остальные 152 строки рамки. Клавиши: a одобрить · r отклонить · d отложить · ↓/↑ дальше/назад. Голоса сохраняются автоматически в localStorage браузера; нажмите «Скачать decisions.json», когда закончите (непроголосованные пункты экспортируются с decision:null).
Одобрить — принять предложенное изменение/ответ на карточке как есть (нет отдельного «одобрить как есть» — одобрение значит согласие с написанным). Отклонить — оставить текущую запись/ответ без изменений. Отложить — пока не уверен(а), решить позже. Поле заметки — для запроса частичной правки вместо полного отклонения.
