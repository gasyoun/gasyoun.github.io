What this is

The Documents/GitHub/ root is not itself a git repository — it is a coordination layer that holds shared instruction files and ~196 standalone git repos cloned side by side. Each subdirectory is its own repo with its own README, dependencies, build system, and CI.

This workspace serves several interconnected missions:

  1. Sanskrit dictionary digitization — the Cologne Digital Sanskrit Lexicon (CDSL) ecosystem: source data, correction pipelines, comparative microstructural analysis, TEI/OntoLex standards, PHP and Python APIs, and spell-checking across dictionaries (MW, PW, PWG, PWK, AP90, etc.).
  2. Russian translations of Sanskrit dictionaries — translator-first dictionary projects (kosha) and Russian-translation tracks inside SanskritLexicography/.
  3. An online Sanskrit learning platform — Systema-Sanscriticum, a Laravel application deployed at samskrte.ru (with a sibling at samskrtam.ru).
  4. Sanskrit grammar and pedagogy — grammar materials (Bühler, Kochergina, Knauer), wave-notation verse visualizer (SanskritKaraoke), spoken/Telegram Sanskrit corpora.
  5. Indological scholarly archives — conference program archives (IndologyScholars), the Russian poetic translation of the Ramayana (RussianRamayana).
  6. Russian writing-style tools — RuWritingStyles, a PyPI-published CLI pipeline with eval harness and Web Studio.
  7. Agent/LLM harness tooling — Claude Code hooks/skills, Codex twins, a 16-step hyperresearch research pipeline, and cross-repo management infrastructure.

Coordination layer

RepoRole
github-spine/Org-level spine — holds shared CLAUDE.md, AGENTS.md, SHARED_CODE.md, SKILLS_INDEX.md, and template packs (PR, CI, CoC). Deployed to the workspace root so every agent session picks them up automatically.
Uprava/Cross-repo management hub — GTD rollup, project interlinks, findings, epistemic registries (assumptions, contradictions, gaps, dead ends, recipes, staleness, glossary), handoff store, articles dashboard, and the tools fleet. Private repo.
claude-config/Version-controlled backup of ~/.claude — hooks, commands, agents, skills, settings. Hooks enforce Markdown and convention rules deterministically.

The root-level CLAUDE.md is the org-level instruction file loaded by Claude Code for every repo under this workspace. It describes the hyperresearch pipeline and scholarly API integration.

Installation

There is no workspace-wide installer. Each subdirectory repo has its own setup.

Prerequisites

  • Python 3.9+ — the floor enforced across the estate via Uprava/tools/pyfloor.py.
  • Node.js — for JavaScript-based projects (csl-atlas, csl-guides, deepseek-harness, etc.).
  • PHP 8+ / Composer — for Systema-Sanscriticum (Laravel) and csl-apidev.
  • Git — for cloning individual repos.

Cloning a specific project

git clone https://github.com/gasyoun/<repo-name>.git
# or from the sanskrit-lexicon org:
git clone https://github.com/sanskrit-lexicon/<repo-name>.git

Then follow that repo's own README.md for its specific installation steps.

Python projects (typical pattern)

cd <repo-name>
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt   # or: pip install -e . if pyproject.toml exists

Laravel project (Systema-Sanscriticum)

cd Systema-Sanscriticum
composer install
cp .env.example .env
php artisan key:generate

Common questions

Is this a monorepo?

No. The root Documents/GitHub/ is not a git repository. Each subdirectory is a standalone git repo hosted on GitHub under gasyoun or the sanskrit-lexicon organization.

How do I find what to work on?

Read Uprava/GTD_NEXT_ACTIONS.md — the cross-repo GTD rollup with human actions (@DO / @DECIDE / @WAITING) and engineering resume-points.

How are agent instructions shared across repos?

The github-spine/ repo holds CLAUDE.md and AGENTS.md, deployed to the workspace root. Claude Code and Codex pick them up automatically for every repo. The always-on CLAUDE.md stays under a 3,000-token budget; the full skill catalogue lives in github-spine/SKILLS_INDEX.md.

Where does the Sanskrit learning platform live?

Systema-Sanscriticum/ — a Laravel application deployed at samskrte.ru.

Known limitations

  • No workspace-level build or CI. Each repo is independent.
  • No root .gitignore. The .zcodeignore serves the ZCode IDE; each subdirectory repo has its own .gitignore.
  • Uprava is private. Several of its docs are unpublished. GitHub Pages is intentionally not enabled.
  • hyperresearch CLI is not on PATH. Must be invoked via its full path.
  • Python interpreter fragmentation on macOS. System python3 may be 3.9.x; newer builds may only be reachable as python3.13.
  • Some repos are stubs. Several scaffolded directories in github-spine/ carry only a stub CHANGELOG.md.
  • No Go, Rust, Ruby, C/C++, or Java. The estate is Python, PHP, JavaScript/TypeScript, HTML/CSS, and Shell.
