04 · teaching notes

How to use this in class

  • Start with the source buckets, not the words. Under terms by root the archive holds 959 named dhātu families; under terms by Proto-Indo-European root another 556. A student who browses these sees that Sanskrit vocabulary is generated from roots, not collected as a word list.
  • Contrast inheritance with borrowing. There are only 50 donor-language buckets but 1,576 compound entries. Ask students to find a borrowed word and a built word, then compare how Wiktionary describes each.
  • Use the cross-listed words as an exercise. Give a lemma filed under three categories and ask which answer — where from, how built, how sure — each tag gives. The tags are complementary, not competing.
  • Mark the reconstructions. The archive holds 32 entries prefixed Reconstruction: — not attested forms, but scholarly reconstructions. Wiktionary keeps them in the same categories, which is precisely why an "evidence" lens matters.
  • Never add c and e. c counts subcategories, e counts word pages. They measure different things and the explorer keeps them apart.
