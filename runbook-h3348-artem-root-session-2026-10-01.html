0. Состояние на 03-09 (что известно)

  1. www/samskrtam.ru/index.php — обфусцированный goto-имплант, 22 057 байт, права 444; регенерируется бокс-сайд реврайтером (FTP DELE не держит).
  2. wp-includes/images/ — GET-бэкдоры xit-3x.gif (20 953 B), xit-2x.gif, wpspin-1x/2x.gif; возрождаются за секунды после удаления (проверено 03-09).
  3. Динамика (PHP) тормозит 12–35 s/запрос — имплант делает исходящий curl перед отдачей; главная спасена статикой (index.html, переустановлен 03-09).
  4. Векторы входа НЕ известны; админ-ростер чистый (9 легитимных), плагины чистые (проверено 03-09).
  5. Root SSH на .95 до сих пор Permission denied для всех наших ключей; .92 видит .95 по LAN (192.168.200.95, ping 0.3 ms).

1. Сессия (по порядку, не пропускать)

  1. Артём открывает root SSH на .95 (или даёт агенту одноразовый доступ/консоль ISPmanager под root).
  2. Охота на персистенс реврайтера — НАЙТИ ДО ТОГО, как чистить файлы (иначе восстановит):
    1. for u in $(cut -d: -f1 /etc/passwd); do crontab -u $u -l 2>/dev/null | grep -v '^#'; done + ls -la /etc/cron* + cat /etc/crontab.
    2. systemctl list-timers --all; ls /etc/systemd/system/ | grep -v wants.
    3. grep -r auto_prepend_file /etc/php* /etc/php.d/ 2>/dev/null; php-fpm пулы: grep -r "php_admin_value\|php_value" /etc/php-fpm*.
    4. Панель: ISPmanager → планировщик + php настройки домена (веб-интерфейс уровня root).
    5. Ловушка на писателе: apt/yum install inotify-tools; inotifywait -m -e create,modify,attrib /var/www/samskrtam/data/www/samskrtam.ru/index.php — кто трогает, тот и реврайтер (см. PID → lsof -p PID, cat /proc/PID/cmdline, путь бинарника).
  3. Убить персистенс (процесс + его автозапуск), только потом:
  4. Заменить имплант: cd /root && unzip -o wordpress-7.0.4.zip wordpress/wp-includes/… wordpress/index.php — из архива /root/wordpress-7.0.4.zip (sha256 f0885ad10c35ac87e70517bc5789275cd54ccac052222a58acfb7b9f870082b0, уже на .92, перенести) взять стоковый index.php (405 B) → положить в docroot, chown как у соседей, права 644. Проверить: curl -s https://samskrtam.ru/cart/ -o /dev/null -w '%{http_code} %{time_starttransfer}\n' → 200 и < 1 s (имплант мёртв). 500 на /cart/ = стоп по килл-свитчу (H3348 § Hardening legs 1).
  5. Удалить xit-семью: rm -f wp-includes/images/xit-*.gif wp-includes/images/wpspin-*.gif и ВСЕ filefuns.php/BiaoJiOk-маркеры по дереву. Через 1–2 мин повторный curl каждого — файлы не должны вернуться (возвращаются = реврайтер жив, шаг 2 сделан не до конца).
  6. Чекsum-диф ядра: на Mac/с .92 запустить python3 tools/h3348_integrity_scan.py --out docs/evidence_h3348 --stock-zip /root/wordpress-7.0.4.zip (FTP-ходок по wp-admin/wp-includes против официального манифеста; DIFFERS-файлы → замена стоковыми).
  7. Truth-pass ×2 с интервалом ≥30 мин: python3 tools/eradicate_samskrtam.py --check (после каждого — записать результат в лог). Оба должны быть CLEAN.
  8. Вердикт-памятка: OxAlpha пишет VERDICT_…CLEAN…md + /handoff-close H3348 — только после двух CLEAN и суток зелёного вочдога (ssh root@193.232.229.92 'tail /var/log/samskrtam-watch.jsonl').
  9. Ротации (тем же днём):
    1. Пароль БД в wp-config.php (+ обновить в .env-ах, где он есть).
    2. FTP/панель-пароль → обновить ~/.secrets/ftp_samskrtam.env и ORS-FAQ/.env.deploy в тот же проход.
    3. WP: пере-выпустить App Password агента, по желанию re-rotate соли (уже раз 19-08).
    4. WooCommerce API-ключи + консультация с Точкой (смена мерчант-кредов) — через MG.
  10. После CLEAN: выключить крон-репинер и вочдог-миграцию: /root/samskrtam_home_repin.py + его */5 cron на .92 больше не нужны (главную снова отдаёт WP/Rocket) — снять строку из crontab; вочдог оставить (поменять baseline xit-семьи на 404 после искоренения). Включить авто-обновления безопасности или подтвердить месячный ручной ритм H3185; пересобрать Rocket-кэш; снять index.html-заплатку (пусть WP снова отдаёт главную) только после суток чистой динамики.

2. Красные линии

  1. Никаких обновлений ядра/плагинов по FTP до убийства реврайтера (550 на живых loader'ах = mixed tree; килл-свитч /cart/ 500).
  2. Не чистить файлы до убийства персистенса — бесполезно, восстановит (доказано 21-08, 24-08, 03-09).
  3. Не пушить креды в репо; пароли — только в ~/.secrets/.env + смена в тот же проход.
  4. «Чисто» объявляет только двухкратный CLEAN truth-pass + зелёный вочдог; единичный проход — не вердикт.
