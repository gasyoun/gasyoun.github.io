DATA_LAYERS_CENSUS.md — the data we own but never counted

_Created: 06-07-2026 · Last updated: 29-10-2026_

Purpose. A QA/gap-finding census of the data layers across the ~85 canonical repos, built by harvesting the filesystem (not the curated inventory). Where FEATURES_INDEX.md answers *"what did we consciously register as an asset?"*, this file answers the opposite: what large data is sitting on disk that was never raised to asset level, never counted, and never analysed? It is a defect-finder, not a catalogue — every row is meant to prompt "should this be backed up / registered / deduplicated / turned into a statistic?".

Scope vs. the kosha manifest (ruling F7, 26-08-2026). kosha/data/manifest/datasets.json is the registry for published, fetchable derived datasets — the ones another repo or a human is meant to pull down and consume. This census stays the human survey of large on-disk data, including data that is not publishable (rights-uncertain, personal, or simply not worth shipping) — a giant belongs here whether or not it will ever earn a manifest row.
